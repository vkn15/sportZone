# 📖 Project Overview

SportsZone is a responsive Sports Equipment E-Commerce website developed using HTML5, CSS3 and Vanilla JavaScript.

The project is designed for college-level frontend training and demonstrates how an online shopping website works without using any backend technologies.

All data is stored using the browser's LocalStorage.

---

# 🎯 Project Objectives

- Learn HTML5 page structure
- Practice CSS layouts and responsive design
- Understand Vanilla JavaScript
- Learn LocalStorage
- Implement Cart & Wishlist
- Create Login & Registration System
- Build Checkout Flow
- Create Professional College Project
